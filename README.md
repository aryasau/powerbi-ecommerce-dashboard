# E-Commerce Sales Dashboard (Power BI)

## Overview
This dashboard analyzes sales performance across product categories, locations, and customer segments.

## Key KPIs
- Total Sales: 30M
- Total Orders: 134K
- Total Quantity: 713K
- Average Rating: 2.73

## Features
- Category-wise sales analysis
- Location-based insights
- Delivery type comparison
- Interactive filtering using slicers

## Tools Used
- Power BI
- DAX
